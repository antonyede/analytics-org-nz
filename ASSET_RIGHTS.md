# Content and asset provenance

Antony Ede, owner of analytics.org.nz, explicitly authorised this migration to the public `antonyede/analytics-org-nz` repository, including wholesale copying of the published site content and assets and public GitHub hosting.

This repository does **not** apply a new blanket licence to that material. Existing copyright and licence terms continue to apply. Third-party photographs, logos, fonts, jQuery and Webflow runtime code are retained for the authorised migration; ownership and redistribution rights are not independently established by the capture process. Preserve embedded copyright/licence notices. Review any third-party font or asset terms before reusing this material outside this migration.

`source/routes.json` records the URLs, status codes, capture time and hashes of published HTML. `source/assets.json` records each downloaded asset URL, original SHA-256 and byte count. `source/assets/` contains original downloaded bytes; `docs/assets/` contains the hosted copies, with CSS asset URLs rewritten to local paths. No credentials, Webflow account exports or private content were used.
